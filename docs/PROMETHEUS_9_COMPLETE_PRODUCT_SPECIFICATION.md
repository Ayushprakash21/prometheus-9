## 1. EXECUTIVE OVERVIEW

**PROMETHEUS-9** is an enterprise-grade autonomous marketing, creative production, and growth operating system designed to run an organization's complete digital marketing operation without requiring manual daily operation or fragmented third-party agency handoffs.

The system executes the continuous closed-loop growth cycle:
$$\text{RESEARCH} \longrightarrow \text{STRATEGIZE} \longrightarrow \text{PLAN} \longrightarrow \text{CREATE} \longrightarrow \text{VALIDATE} \longrightarrow \text{PRODUCE} \longrightarrow \text{APPROVE} \longrightarrow \text{PUBLISH} \longrightarrow \text{MEASURE} \longrightarrow \text{LEARN} \longrightarrow \text{OPTIMIZE}$$

### Foundational Principles
1. **Simplicity Over Spectacle:** Following the usability philosophy of ApplyWise AI, the user interface provides clear navigation, consistent page layouts, functional forms, and robust modals. Experimental circular galaxy abstractions are strictly rejected in favor of high-throughput operational clarity.
2. **Deterministic Truth & Verified Claims:** Generative AI is strictly constrained by a deterministic claims guardrail. AI agents are prohibited from inventing features, non-existent statistics, or unauthorized ROI guarantees.
3. **Charcoal & Copper Luxury Aesthetic:** High-end dark editorial styling featuring Obsidian Charcoal (`#202221`), Graphite (`#414542`), Burnished Copper (`#A16C50`), Champagne Beige (`#C9B49B`), and Warm Ivory (`#EEE8DE`).

## 4. DETERMINISTIC CLAIMS GUARD & BRAND COMPLIANCE

To protect enterprise brands against legal and reputational liability:
- Every product registers a list of **Verified Claims** (contractual SLAs, verified metrics, certified features).
- Every product registers **Prohibited Claims** (e.g., unsubstantiated guarantees, competitive disparagements).
- Before any script or content piece enters the publishing queue, the **Compliance Guardian** runs a factual consistency evaluation. Unverified assertions cause immediate rejection back to the creative desk with required revisions.

## 5. PROGRAMMATIC VIDEO PRODUCTION PIPELINE

PROMETHEUS-9 features an embedded video assembly engine powered by **FFmpeg**:
- **Format Support:** 9:16 Vertical (1080x1920 for YouTube Shorts, Reels, TikTok), 16:9 Widescreen (1920x1080 for YouTube Long-Form, LinkedIn), and 1:1 Square (1080x1080).
- **Automated Subtitling:** Burns synchronized SRT subtitle tracks directly into video streams with high-contrast luxury editorial typography.
- **Audio Mixing:** Automatically mixes speech voiceovers with low-gain ambient audio tracks.
- **Hardware Acceleration:** Native CUDA / QSV / VideoToolbox detection with automatic fallback to high-efficiency software encoding (`libx264`, `aac`).

## 6. MULTI-CHANNEL SOCIAL PUBLISHING & OAUTH STATE MACHINE

- **Supported Channels:** YouTube (Data API v3), LinkedIn (Marketing Developer API), X / Twitter (API v2), Meta / Instagram / Facebook (Graph API), and TikTok (Content Posting API).
- **Token Security:** OAuth access and refresh tokens are stored encrypted in SQLite WAL storage using AES-256-GCM.
- **Publishing State Machine:**
  $$\text{DRAFT} \longrightarrow \text{SCHEDULED} \longrightarrow \text{QUEUED} \longrightarrow \text{PUBLISHING} \longrightarrow \begin{cases} \text{PUBLISHED} & \text{(Captures platform post ID and URL)} \\ \text{FAILED} & \text{(Triggers exponential backoff retry)} \end{cases}$$
- **Budget Caps:** Automated spending hard stops prevent any paid distribution from exceeding the user-configured monthly budget threshold.

## 7. BACKEND CORE & SECURITY HARDENING

- **Backend Stack:** Python 3.12, FastAPI, Pydantic v2, SQLAlchemy 2.0 (Async), SQLite WAL mode, Alembic migrations.
- **Authentication:** Argon2id / bcrypt password hashing with signed JWT bearer tokens.
- **Tenant Isolation:** Multi-tenant organization boundaries strictly enforced across all 18 database entities with foreign key constraints.
- **Scheduler Concurrency:** Persistent SQLite task queue with atomic task claiming (`UPDATE ... WHERE status = 'queued' AND worker_id IS NULL`), stale worker recovery, and dead-letter queues.
